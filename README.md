# Currículo Online - Italo Dias Reis

Este repositório contém o código-fonte do meu currículo online, desenvolvido com HTML, CSS e JavaScript, com o objetivo de apresentar minha trajetória acadêmica, habilidades, projetos e informações de contato de forma moderna e acessível.

## Sobre o projeto

O site foi criado como uma página pessoal hospedada via GitHub Pages.  
Nele, apresento informações sobre minha formação, habilidades técnicas, experiências, projetos pessoais e acadêmicos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git e GitHub

## Funcionalidades

- Página inicial com apresentação pessoal
- Seção de currículo
- Seção de habilidades
- Aba de projetos com links e modal de contato acadêmico
- Design responsivo
- Tema escuro moderno

## Projetos em destaque

- **Rugido Podcast** — projeto estudantil voltado à comunicação e informação entre estudantes.
- **UNIFEI** — espaço dedicado ao contato acadêmico institucional.
- **ASIMOV JR** — atuação e desenvolvimento dentro da empresa júnior.

## Objetivo

Este projeto tem como objetivo reunir minhas principais informações profissionais e acadêmicas em um só lugar, funcionando como um portfólio digital para oportunidades na área de tecnologia, ciência de dados e desenvolvimento.

## Acesse o site

Em breve disponível via GitHub Pages.
